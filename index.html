    Color tags

    Wrap words in tags to color them:

    • <gold>Last Whisper</gold> for items and keywords
    • <red>Draven</red> for enemies, <blue>Leona</blue> for allies
    • <ping>…</ping> for smart ping text, <info>…</info> for statuses like " - Ready"
    • <green> and <cyan> for stat values, <yellow> for bounty gold
    • <#ff66cc>anything</> for any hex color

    Game fonts

    Chat and the scoreboard match the game exactly with League's own fonts. They can't be shared from this site, so download them from CommunityDragon, which hosts League's game files, then load them here.

    1. Click Download for each font. Save the files anywhere.
    2. Click Load font files and pick them. You can pick both at once.

    Any other font file works too. It becomes the chat font.

    Saved in this browser

    Loaded fonts stay in this browser for your next visit. They aren't uploaded anywhere.
